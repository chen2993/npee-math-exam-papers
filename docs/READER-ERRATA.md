## 一、两种错误必须分开

读者提交的是「**这题应该是这样**」，但对我们来说有两种完全不同的性质：

1. **识别错误**——扫描页上写的是 A，我们录成了 B。这类是**我们的缺陷**，回图即可确定，
   直接修正，且修正后与源页逐字一致。
2. **来源书自身有误**——扫描页上写的确实是 B（题目本身印错/漏印）。题库的契约是
   **忠实转写源页**，所以这类改动等于「有意偏离来源」，属产品决策：
   改了，题库就不再是来源的忠实记录；不改，成品会带着原书的错误。

因此本轮的判定不是「谁说得对」，而是**先看源页印的是什么**。4 条被归到第二类的，
都在源页上逐字确认过题库没有录错。

又抓到两处同一批次的识别错误：

## 五、待用户决策：4 条来源书自身的错误

这 4 条**题库与源页完全一致**，改它们就是有意偏离来源。以下给出「源页怎么印、
读者怎么说、我们建议怎么处理」：

| 编号 | 位置 | 源页现状 | 读者主张 | 影响 | 建议 |
| --- | --- | --- | --- | --- | --- |
| A | `2024/math2/chaoyue10/5` q18 | `∫₀ˣ t²[y(t)+1]dt` | 应为 `t²[y′(t)+1]` | 按原式解出 `y` 含 `e^{±√2x}`；补上导数后答案化简为 `y=e^{2x}-x` | 疑为源书漏印撇号，**建议按勘误写**（同题在数一/数三卷次也有，需一并处理） |
| B | `2025/math1/chaoyue10/6` q8 ④ | `P(A∪B̄)P(AB̄)≤P(A)P(B)` | 去掉两处上划线 | 会改变 ④ 的真假，进而改变选项计数 | 数三同题本来就印 `P(A∪B)P(AB)`（③ 也作 `P(A^c-B)`），读者要的很可能是数三那一版；**建议先看官方答案再定** |
| C | `2024/math1/zhangyu8/2` q5 | 第一个矩阵印 `B CB`，第二个印 `B BC` | 统一为 `B BC` | 改后选项答案变为 B（读者亦注明「这是张宇八套卷勘误、非文件错误」） | 属**原书勘误**，若成品要跟原书勘误走则改，否则保持与源页一致 |
| D | `2024/math1/chaoyue10/2` q15 | `(A-E)x=0` 的基础解系印 `α₁`（与前一式同符号，逻辑上矛盾） | 应为 `α₃`（数三同题正是 `α₃`） | 不改则题干自相矛盾（`α₁` 同时是 `A` 的特征向量，`(A-E)α₁≠0`） | 性质同 A，**建议按勘误写** |
| E | `2024/math1/chaoyue10/2` q4 B 选项 | 左侧 `∮_L`、右侧 `∫_L` | 两侧都用 `∮_L` | 与 A/C/D 三项体例不一致 | 属排版/漏印，**建议按勘误写**（只影响记号，不改题意） |

要点：**A、D、E 若照改，题库就不再逐字等于源页**。因此本工具把这类改动放在
`SOURCE_FIXES` 里，默认只报告不写；用户确认后可一次性落盘：

```powershell
python -m npee_math_papers.maintenance.apply_reader_errata --apply --include-source-fixes
```

## 六、复算

### 6.1 读者版清单（LaTeX → 三个 PDF）

给读者的成品不是本文件，而是按科目分开的三份。它们属于**贾基八十五套卷这个组卷包**，
所以源文件与产物都放在该包的目录里：

| 文件 | 说明 |
| --- | --- |
| `composition/jiaji-eighty-five/errata/errata-body.tex` | 正文与版式（ctexart + xelatex）：标题居中，套卷名为二级标题，条目只有「题号：原内容 → 正确内容」 |
| `composition/jiaji-eighty-five/errata/errata-math1/2/3.tex` | 三份驱动文件，各自设置科目后 `\input{errata-body.tex}` |
| `dist/jiaji-eighty-five/errata/贾基八十五套卷勘误清单-数学{一,二,三}.pdf` | 编译产物（各 1 页）；红=原印刷、绿=更正，`（原书）`标注源书笔误 |

格式遵循「年份-试卷名-套数 / 题号：原内容 → 正确内容」；不含提交者昵称与本地路径。

```powershell
$env:Path = "D:\texlive\2026\bin\windows;" + $env:Path
cd composition\jiaji-eighty-five\errata
# 中间文件与 PDF 都写到 dist/，源目录保持只有 .tex
$out = "..\..\..\dist\jiaji-eighty-five\errata"
foreach ($m in @("math1","math2","math3")) {
  xelatex -interaction=nonstopmode -halt-on-error -output-directory="$out" "errata-$m.tex"
}
Rename-Item "$out\errata-math1.pdf" "贾基八十五套卷勘误清单-数学一.pdf"
Rename-Item "$out\errata-math2.pdf" "贾基八十五套卷勘误清单-数学二.pdf"
Rename-Item "$out\errata-math3.pdf" "贾基八十五套卷勘误清单-数学三.pdf"
```
