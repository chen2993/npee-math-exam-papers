# 人类使用指南

本文档面向使用管理台的人。你在命令行跑一条命令，浏览器里管理题库与组卷。

## 一、启动

```powershell
.\start-npee.ps1
```

或双击 `start-npee.bat`。启动后命令行窗口只显示三行：后端地址、前端地址、停止提示，
并自动打开浏览器。

参数：

```powershell
.\start-npee.ps1 -WebPort 5173 -ApiPort 8766      # 换端口
.\start-npee.ps1 -NoBrowser                        # 不自动开浏览器
```

停止：命令行窗口按 `Ctrl+C`。

## 二、界面

### 仪表盘

题库总览：套卷数、题目数、系列分布。点击某系列直接跳到该系列的套卷列表。

### 套卷

- 顶部按**年份、科目、系列、排序**筛选，全部在服务端执行，因此总数与翻页始终
  描述的是筛选后的结果；
- **搜索框检索全库**（不是当前页）：可输入系列名、系列 ID、年份或套号，例如
  `zhangyu8 2024`、`chaoyue10`。输入停顿时才发请求，按回车立即检索，
  输入框右侧的 × 或 `Esc` 清空；
- 本页**只读**：列出套卷、打开题目抽屉，不做任何组卷操作；选卷与排序都在「组卷」页，
  两处功能互不依赖。

题目详情是右侧抽屉：

- 题面用 KaTeX 渲染；
- **图形由服务端编译为 SVG 显示**，所见即真实 LaTeX 输出；
- 自上而下逐题排列，含选项与子问；
- 按 `Esc` 关闭。

### 组卷

左侧是已选套卷：**拖动行可调整打印顺序**，也可用上移/下移按钮微调，或移除某套。
右侧是文档设置；下方是全量选卷。

下方选卷区与「套卷」页使用同一套筛选与排序控件，另有「加入本页全部」按钮，
适合按系列整批选卷。

文档设置包括：页面（A3/A4）、纸色、**间距**、**留白**、目录、封面页、水印。

**间距与留白是两件事**，互不影响：

| 设置 | 作用 |
| --- | --- |
| 间距＝紧凑 | 全卷自然连排，客观题与解答题共用一套排版 |
| 间距＝宽松 | 只改**解答题**：17–18 题共用一页，之后每题独占一页，给作答留下书写空间 |
| 留白＝开 | 只加空白：每套卷补足到整页、封面后加一张空白页、目录凑成偶数页，使双面打印时每套卷都从右手页开始 |
| 留白＝关 | 不留空白页，卷子有多长就多长 |

默认是**紧凑 + 留白**（也就是以前的「打印版」），在 A3 与 A4 各出一份。
旧组卷包里的 `print` / `a4-blank` 会被读成「紧凑 + 留白」，行为与以前一致。

「仓库组卷包」一栏列出 `composition/` 下的正式组卷包：点一下就打开成一份草稿
（**原包不动**），改完点「保存回 <包名>」写回原文件；复制出来的副本不会覆盖原包。

**水印默认关闭**。需要时在「页面水印」里勾选并填写文本；「启用前 ★ 绝密」
密级标记同样默认关闭，需要时用版式类选项 `securitymark` 打开。

点「编译导出」生成 PDF 并下载。编译在服务端后台跑 XeLaTeX，通常十几秒到几十秒：

- 页面顶部的进度条显示阶段、已用时间与任务 ID；
- **可以离开此页面**继续做别的事，编译不会中断（即使刷新页面也会继续），
  完成后回到「组卷」即可下载；
- 版式组合（如 A3 + A4）会产生多个产物文件，每个都有独立的「下载」按钮。

**版本绑定**：组卷会记住每套卷在选题时的内容版本。若之后题库变动，编译会提示哪几套
变了，避免导出与预期不一致的卷子。

### 快捷键

按 `?`（或点右上角键盘图标）查看快捷键表：

| 按键 | 作用 |
| --- | --- |
| `/` | 跳到套卷列表并聚焦搜索框 |
| `[` | 收起 / 展开侧栏 |
| `Ctrl/⌘ + G` | 跳到仪表盘 |
| `Ctrl/⌘ + Shift + P` | 跳到套卷列表 |
| `Ctrl/⌘ + Shift + E` | 跳到组卷 |
| `?` | 显示 / 隐藏快捷键表 |
| `Esc` | 关闭弹层与抽屉 |

在输入框内打字时快捷键不生效。

### 操作日志

统一查看 **MCP 工具调用**（Agent 操作）与 **HTTP 请求**（前端操作）：

- 每条显示来源、工具名/路径、成功或失败、耗时、时间；
- **来源一眼可分**：HTTP 行左侧是蓝色竖条 + `HTTP 请求` 标签，MCP 行是青色竖条 +
  `MCP 工具`标签；失败的整行标红；
- HTTP 行额外显示**请求方法**徽章（GET/POST/PUT/DELETE 各自配色）与**真实状态码**
  （2xx 绿、4xx 琥珀、5xx 红），MCP 行显示工具名；
- 耗时 ≥1.5 秒标记「慢」，便于发现卡顿的编译；
- 带「正文」标记的行可点击展开，**查看完整的请求体与响应体**（MCP 调用则是完整的
  工具入参与其返回值）；JSON 可逐层折叠，也可一键复制；
- 二进制响应（如编译出的 PDF）只记录类型与大小，不把文件内容写进日志；
- 支持按来源、结果筛选与关键字搜索；**搜索会覆盖请求/响应正文**，因此可以查
  「哪个请求带了 math3」这类问题；
- 默认每 3 秒自动刷新，可关闭；
- 「清空日志」会先确认，避免误删审计记录。

## 三、题库存储

题库在 `.npee-math-papers/`，一套试卷一个可读的 YAML 文件：

```text
.npee-math-papers/
├─ papers/zhangyu8-2024-math1/7.yaml    题库正文
├─ registry.json                        系列注册表
├─ release.json                         版本清单（内容哈希）
├─ index/                               索引（可重建）
├─ sources/                             来源 PDF（不提交）
├─ captures/                            页面图（不提交）
└─ logs/                                操作日志（不提交）
```

YAML 采用字面量块，LaTeX 反斜杠原样保存：

```yaml
stem:
  text: |-
    设 $f(x)=\begin{cases}1,&x\text{ 是整数},\\-1,&x\text{ 不是整数},\end{cases}$
```

## 四、给 Agent 装 MCP

见 [`MCP-SETUP.md`](MCP-SETUP.md)。装好后 Agent 能直接读写题库、组卷、编译；
它的每次工具调用都会出现在前端「操作日志」页。

## 五、常见问题

**端口被占用**：换端口启动，例如 `.\start-npee.ps1 -WebPort 5174 -ApiPort 8767`。

**图形显示为占位提示**：说明本机 XeLaTeX 不可用或该图编译失败。运行
`python -m npee_math_papers.maintenance.check_environment` 查看环境。

**前端页面打不开**：确认命令行窗口显示「已启动」且没有报错。若前端未构建且无 npm，
按提示先构建：`cd npee_math_papers/frontend; npm install; npm run build`。

**日志太多**：写操作会持续累积；在日志页点「清空」，或日志文件超过 4 MB 时自动轮转。
